# Fuente del hero

Coloca aquí el archivo de **Bubblegum Pop** con estos nombres exactos para
que el `@font-face` en `src/index.css` la recoja automáticamente:

- `BubblegumPop.woff2` (preferido)
- `BubblegumPop.woff` (fallback opcional)

No hace falta tocar código: en cuanto el archivo esté en esta carpeta y se
haga deploy, el título del hero la usa.
